# 仁心养生行 · 出入库管理

在线访问：启用 GitHub Pages 后自动生成（`https://eric-ljf.github.io/renxin-inventory/`）

本地预览：直接双击打开 `index.html`

### 核心功能
- **道地药材台账**：支持 51 味精选药材出入库台账、药性功效说明、分类检索与实时搜索。
- **库存预警**：低库存预警提示（可自定义单品阈值）、防超卖校验。
- **数据分析看板**：总 SKU、实盘总库存、今日流水统计、30天畅销榜与补货榜。
- **数据备份与迁移**：支持导出流水为 CSV 格式、全量数据 JSON 备份与一键还原导入。
